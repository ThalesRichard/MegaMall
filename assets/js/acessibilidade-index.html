Declaração de acessibilidade

A MegaMall quer ser usada por todas as pessoas. Este site foi construído buscando seguir as diretrizes WCAG 2.2 (nível AA) e as boas práticas do eMAG, conforme o art. 63 da Lei Brasileira de Inclusão (Lei nº 13.146/2015). É um projeto acadêmico e continua em melhoria.

Como abrir o menu de acessibilidade

Em todas as páginas há um botão laranja com o símbolo de acessibilidade na lateral direita da tela. Clique nele, ou use o atalho Alt + 0, para abrir o painel. Para fechar, use o botão ✕ ou a tecla Esc.

O que cada recurso faz

  • Tamanho do texto: os botões A− e A+ mudam o texto entre 100%, 125%, 150% e 175%.
  • Modo escuro: troca o fundo claro por um fundo escuro, mais confortável em ambientes com pouca luz.
  • Alto contraste: deixa o fundo preto, o texto branco e os links e botões amarelos.
  • Espaçamento do texto: aumenta o espaço entre linhas, palavras e letras.
  • Fonte legível: usa uma fonte sem serifa de formas bem distintas.
  • Destacar links: sublinha e deixa em negrito todos os links.
  • Pausar animações: para o carrossel e as transições da página.
  • Cursor grande: aumenta o ponteiro do mouse.
  • Libras: abre o VLibras, tradutor de português para a Língua Brasileira de Sinais do governo federal (precisa de internet).
  • Restaurar padrão: desfaz todas as escolhas.

Atalhos de teclado

  • Alt + 1: ir para o conteúdo
  • Alt + 2: ir para o início
  • Alt + 3: ir para o menu
  • Alt + 4: ir para a busca
  • Alt + 0: abrir ou fechar o menu de acessibilidade

Todo o site também pode ser usado só com o teclado (Tab para avançar, Enter para ativar). No começo de cada página há o link "Pular para o conteúdo".

Encontrou um problema?

Conte para nós pela página de contato. Suas escolhas de acessibilidade ficam salvas apenas no seu navegador.
